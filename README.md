# 📖 Project Overview

The Smart Wearable Safety Jacket for Gem Miners in Sri Lanka is an IoT-based safety solution designed to improve the health, safety, and emergency response capabilities of gem miners working in hazardous underground environments.

The system continuously monitors miners’ vital signs and surrounding environmental conditions using integrated sensors and provides real-time alerts during dangerous situations.

This project aims to improve miner safety and reduce rescue response time during underground emergencies through wearable technology.

# 🔧 Hardware Components

## 🩺 Health Monitoring Sensors

| Sensor | Purpose |
|---|---|
| MAX30102 | Heart Rate & SpO₂ Monitoring |
| MLX90614 | Non-Contact Temperature Monitoring |

---

## 🌍 Environmental Monitoring Sensors

| Sensor | Purpose |
|---|---|
| MQ135 | Air Quality Monitoring |
| MQ7 | Carbon Monoxide Detection |
| DHT22 | Humidity Monitoring |

## 📡 Communication & Tracking Components

| Component | Function |
|---|---|

| LoRa Antenna | Signal Transmission |
| NEO-6M GPS | Real-Time Location Tracking |
| MPU6050 | Fall Detection & Motion Monitoring |
| SOS Push Button | Emergency Activation |
| BMP280 | Pressure Monitoring |
